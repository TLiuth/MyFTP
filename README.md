O programa MyFTP pode ser executado no modo de terminal ou no modo de interface.


Para executar no modo terminal:
1º Abrir o prompt de comando nesse diretório (MyFTP):
2º Digite "python3 main.py"


Para executar no modo de interface:
1º Mova para o diretório gui (cd gui)
2º Digite "python3 shared_interfaces.py"

==========================

Selecione, na primeira execução, o modo servidor. Defina para ele um ip

Em seguida, execute o programa novamente, em outro terminal. Entre como cliente, fornecendo o mesmo ip
